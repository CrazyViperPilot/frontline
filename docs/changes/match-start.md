**Signierter Match-Start** (§17 „Konten“): Eine gewertete Partie (Kasse am Konto) startet nur mit einem Token des Servers, der bis zu 3 Tokens auf Vorrat ausgibt (auch offline nutzbar). Das Partieende meldet den Endstand per `api/match.php` (`finish`); der Server prüft Signatur, Einmaligkeit und die Start-Kasse und begrenzt den Zuwachs je Partie. Ohne Token läuft die Partie ungewertet. Die alte Aktion `wallet` entfällt.
